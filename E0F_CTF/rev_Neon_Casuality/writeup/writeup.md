# Neon Casuality - Reverse Engineering Writeup

## Challenge Overview
- **Category:** Reverse Engineering
- **Points:** 752
- **Difficulty:** Insane
- **Target File:** `neon-causality.exe` (64-bit Windows PE)

## Analysis & Vulnerability / Mechanism Discovery
1. **Input Parsing & Verification**:
   - The binary reads an input string and checks length `cmp rax, 0x35` (53 bytes: 4 bytes `e0f{`, 48 inner bytes, 1 byte `}`).
   - Inner 48 bytes are verified to be printable ASCII (range `0x20..0x7e`).

2. **Causal Equation System**:
   - The binary initializes 48 6-byte records generated by `0x140001b70`.
   - Each 6-byte record consists of 4 byte indices `(b0, b1, b2, b3)` (or `0xff` for unused) and a 16-bit target integer `w4`.
   - For each record, pseudo-random constants are generated via a 64-bit mixing function seeded by `(b0, b1, b2, b3)`.
   - A non-linear polynomial in the flag bytes `flag[b0], flag[b1], flag[b2], flag[b3]` is evaluated and reduced modulo 257 (a Fermat prime).
   - The output modulo 257 must match `w4`.

3. **Causality DAG / Triangular Structure**:
   - Analyzing the dependency graph of the 48 equations reveals a Directed Acyclic Graph (DAG):
     - Equation 10 depends on only 1 unknown variable (`flag[14]`).
     - Equation 47 depends on `flag[14]` (now known) and `flag[46]`.
     - Equation 45 depends on `flag[46]` and `flag[44]`.
     - The remaining equations cascade similarly in causal dependency order.
   - Performing forward substitution / propagation directly in $\mathbb{F}_{257}$ or constraint solving with Z3 uniquely determines all 48 flag bytes.

4. **Verification**:
   - Tested full execution in Unicorn engine.
   - Both the 48 modular equations and subsequent SIMD checksum pass, outputting `resonance`.
