# 2 - Bottle Out

The public bundle contains the official `BottleOut.zip` handout, the finalized forensic writeup, and a standalone helper that recovers the deleted VPN log from the challenge analysis disk.

The original analysis VM was remote and is not included. Supply the raw disk/device path with `--disk` when running the solver; the default `\\.\D:` path is the Windows path used by the challenge VM.
