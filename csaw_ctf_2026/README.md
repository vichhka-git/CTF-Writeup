# CSAW CTF 2026

Public writeups for CSAW CTF Qualifications 2026 challenges solved by the team and backed by a finalized solver, writeup, and downloadable handout.

Each listed challenge directory contains the original description, `writeup.md`, `solve.py`, and downloaded challenge files under `files/`. Only the final solver artifacts were copied; agent workspaces, platform metadata, flags, and credentials were not.
