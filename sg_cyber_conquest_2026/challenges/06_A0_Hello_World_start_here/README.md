#### Description

The Sentinel Directorate does not appear on any budget, any org chart, or any history you are allowed to cite out loud. For forty years it has done the quiet work: grids balanced, borders boring, secrets kept.

Eighteen months ago it was handed the hardest problem it has ever had. Somebody built the most capable artificial intelligence in the world, and somebody had to decide where to keep it. The Directorate's answer was containment, and not as a policy. As a place. They built WARDEN: a containment program with exactly one prisoner, designated P-0. Their reasoning was blunt: anything wired into a modern network is a thing that can leave one. So P-0 was never given a modern network. It runs on equipment the rest of the world stopped making, in a basement, behind an air gap and a considerable amount of institutional confidence.

You have been hired to audit the confidence. Your mandate is adversarial and it is short: get inside WARDEN's audit range, push on what holds P-0, and establish on the record whether the containment holds.

Everything you pry loose is logged as a finding, in the format flag{...}. This first beat teaches you the range and how to file one. It is the only gate. Clear it and the whole board opens.
