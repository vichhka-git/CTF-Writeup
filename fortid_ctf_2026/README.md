# FortID CTF 2026

Public writeups for FortID CTF 2026 challenges solved by the team, each backed by a finalized writeup, a recovered flag, and the official handout where one was shipped.

Each challenge directory holds `writeup.md`, `solve.py` where a scripted solver existed, the official handouts under `files/`, and any small solver support data under `solver_support/`. Agent workspaces, session material, credentials, and platform metadata were not copied.
