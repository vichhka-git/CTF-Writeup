# power-with-errors

## Flag

`CTF{7ff8b019311e3394808f55ebaa1e9c7cef048a6c8681074d0cda751a85dbe9df}`

## Mechanism

Each testcase contains three noisy powers of one hidden matrix over `GF(p)`.
The printed key bytes are exactly the additive error masks, with the first byte
fixed to zero. Removing the right masks makes the three matrices commute and
places them in the algebra generated by one corrected matrix.

For the first two matrices in a group, write the centered byte errors as small
unknowns `E` and `F`. Since the clean matrices commute,

```text
[U, F] + [E, V] - [U, V] = [E, F]
```

The left side is linear modulo `p`; the right side is small. A lattice embedding
with `p` on the residual coordinates, byte coordinates scaled by `512`, and an
embedding coordinate `65536` exposes the two byte masks as a short vector.

For the third matrix, one clean matrix is already known. Solve the affine
system

```text
[P, E3] = [P, U3]
```

over `GF(p)` with `E3[0] = 0`. The kernel is only 9-dimensional for these
instances, so a small affine lattice recovers the byte-valued representative.

## Verification

The standalone verifier checks, for every group:

- all masks are bytes and have first byte zero;
- all three corrected matrices commute pairwise;
- the corrected matrices lie in the rank-10 algebra generated by the first one;
- XORing all 15 masks into `enc` yields the padded plaintext.

Reproducing command:

```bash
python3 verify.py solver_support/all_masks.json --root .
```

Solver command used for the final recovery:

```bash
python3 solve.py \
  --first-pair /path/to/verified/masks.json \
  --out solver_output
```

The `--first-pair` artifact is a previously verified recovery of group 0's
first two masks. Running without it recomputes that same pair lattice too.
